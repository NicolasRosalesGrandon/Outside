# Proxil JLA Latam - Landing Page Corporativa

Proyecto de catálogo digital y centro de recursos para **Proxil Lubricants**, optimizado para el mercado latinoamericano.

## 🚀 Tecnologías Utilizadas
* **HTML5**: Estructura semántica avanzada.
* **CSS3**: Diseño "Dark Mode" premium, Flexbox y animaciones personalizadas.
* **JavaScript**: Lógica de interacción y carga dinámica.
* **GitHub Pages**: Despliegue continuo y hosting estático.

## ✨ Características Principales
* **Diseño Responsive**: Optimizado para dispositivos móviles como el Samsung S25.
* **Catálogo Interactivo**: Navegación por categorías de productos (Gasolina, Diésel, ATF, etc.).
* **Centro de Descargas**: Gestión eficiente de documentación técnica y catálogos en PDF.
* **Certificaciones**: Galería de acreditaciones ISO y aprobaciones OEM (Mercedes-Benz, Volvo, API).

## 🛠️ Estructura del Proyecto
El proyecto sigue una arquitectura de archivos en la raíz para optimizar el SEO y la velocidad de carga en servidores de archivos estáticos.
